Architecture Principles

복잡도를 통제하는 6가지 원칙

01

비파괴 편집

원본은 유지하고 컷, 자막, 위치, 효과를 프로젝트 JSON으로 저장합니다.

02

프록시 프리뷰

브라우저는 저해상도 프록시로 빠르게 편집하고 최종 출력은 원본으로 처리합니다.

03

모듈형 모놀리스

API는 하나로 시작하되 CPU/GPU 작업만 독립 워커로 분리합니다.

04

비동기 작업

변환, 자막, AI 분석, 렌더링은 큐 기반 Job으로 실행하고 상태를 스트리밍합니다.

05

AI는 제안

AI 결과는 미리보기와 승인을 거쳐 Timeline Patch로 적용하며 언제든 복구할 수 있습니다.

06

공통 렌더 명세

브라우저 프리뷰와 서버 렌더러가 동일한 Render Instruction을 해석합니다.

System Architecture

전체 시스템 모식도

대화형 편집은 클라이언트에서, 신뢰성이 필요한 저장과 제어는 API에서, 무거운 처리는 비동기 워커에서 수행합니다.

Media & Rendering

업로드부터 최종 렌더링까지

UPLOAD PIPELINE

미디어 처리

업로드 세션→직접 업로드→검증→프록시→READY
  • Signed Multipart URL로 API 병목 제거
  • 코덱·크기·길이·손상 여부 검증
  • 편집 프록시, 썸네일, 파형, STT 오디오 생성
  • 실패 재시도와 중복 작업 방지
RENDER PIPELINE

최종 출력

Project JSON→Compiler→Render IR→FFmpeg→QC
  • 특정 프로젝트 revision을 고정해 재현성 확보
  • 프리뷰와 서버가 같은 효과 명세 공유
  • 준비·합성·인코딩·업로드 단계별 진행률
  • 완료 파일 무결성 검사 후 CDN URL 발급
!
중요 설계: 프로젝트 JSON을 FFmpeg 명령으로 직접 바꾸지 말고 Render Instruction 중간 계층을 둡니다. 편집 기능 확장과 렌더러 교체 시 결합도를 크게 낮출 수 있습니다.
AI Architecture

AI는 타임라인을 생성하는 보조 엔진

각 AI 모델의 결과를 제품 공통 형식으로 정규화하고, 최종적으로 사용자가 검토할 Timeline Patch를 생성합니다.

Provider 추상화

STT, 배경 제거, LLM, TTS를 인터페이스로 분리해 모델과 외부 API를 교체할 수 있게 합니다.

비용 우선순위

초기에는 외부 API로 검증하고 사용량이 많은 STT와 배경 제거부터 자체 GPU로 전환합니다.

안전한 적용

낮은 신뢰도 표시, 원본 보존, 승인 전 미리보기, 한 번에 되돌리기를 기본 UX로 둡니다.

28-Week Roadmap

Phase별 개발 계획

각 Phase는 기능 목록이 아니라 검증 가능한 사용자 결과로 종료합니다.

1~2주
PHASE 0

기술 검증 및 범위 고정

2주
  • WebCodecs/WebGL 프리뷰와 프레임 탐색 검증
  • 1080p 업로드, 프록시, FFmpeg 컷·자막 렌더링
  • 프로젝트 스키마 v0와 AI 공급자 비용 비교
완료 기준: 10분 영상 업로드 → 프록시 편집 → 두 구간 컷과 자막 포함 MP4 출력 성공
3~5주
PHASE 1

플랫폼 기반 구축

3주
  • 인증, 프로젝트 CRUD, 직접 업로드, 미디어 검증
  • 프록시·썸네일·파형 생성과 작업 큐
  • 자동 저장, revision, 로그·메트릭·스테이징 환경
완료 기준: 2GB 업로드 재개, 실패 자동 재시도, 프로젝트 생성부터 Asset READY까지 전체 흐름 동작
6~12주
PHASE 2

핵심 편집기

7주
  • 멀티트랙, 트림·분할·이동, 재생 헤드, 스냅
  • Undo/Redo, 위치·크기·회전, 텍스트, 자막, 오디오
  • 트랜지션, 720p·1080p 서버 렌더링과 다운로드
완료 기준: 30분 프로젝트 편집·복원, Undo 100단계, 자막·음악·전환을 포함한 1080p 출력
13~18주
PHASE 3

AI 편집 MVP

6주
  • 한·영 자동 자막, 단어 타임코드, 자막 스타일
  • 침묵·필러 후보, 노이즈 제거, 배경 제거
  • 세로 자동 리프레임, AI 미리보기·일괄 복구
완료 기준: 10분 대화 영상을 자막 포함 세로 영상으로 변환하고 모든 AI 변경을 한 번에 되돌림
19~24주
PHASE 4

숏폼 자동 생성

6주
  • 장면·발화 분석과 하이라이트 점수화
  • 15·30·60초 후보 3~5개 자동 생성
  • 자동 컷·자막·리프레임, 제목·설명·해시태그
완료 기준: 30분 영상에서 수정 가능한 완결형 숏폼 후보 3개 이상 생성
25~28주
PHASE 5

베타 안정화 및 출시

4주
  • 부하·브라우저 호환·복구·실패 UX 테스트
  • 사용량 제한, 결제 기반, 보관 정책, 개인정보 삭제
  • 운영 도구, 온보딩, 피드백 수집, 장애 대응
완료 기준: 저장 성공률 99.9%, 렌더 성공률 98%, 사용자별 비용 추적과 운영 진단 가능

주요 리스크와 대응

프리뷰와 출력 불일치

공통 Render Instruction, 기능별 골든 프로젝트, 프레임 비교를 통해 차이를 지속적으로 관리합니다.

GPU·AI 비용 증가

영상 분당 원가를 Job 단위로 기록하고 캐시, 샘플링, Provider 라우팅으로 비용을 통제합니다.

대용량 업로드 실패

Multipart 업로드, 재개, 체크섬 검증, 저장소 직접 전송으로 네트워크 실패를 흡수합니다.

편집 상태 손실

로컬 복구본, 자동 저장, revision 충돌 감지, 주기적 스냅샷으로 프로젝트를 보호합니다.
